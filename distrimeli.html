El problema de negocio

Atender varias cuentas exige mantener separadas las identidades, encontrar conversaciones pendientes y revisar productos sin repetir respuestas o cambios ante una conexión inestable.

La solución

Construí un espacio con bandeja de conversaciones, editor de respuestas, catálogo y reportes. El backend centraliza permisos y conexiones; la IA propone borradores que una persona revisa antes de enviar.

  • Atención multicuentaBandeja de preguntas y posventa con filtros y búsqueda por cuenta, cliente o referencia.
  • Asistencia de IASugerencias de respuesta con revisión humana y conservación del texto que el usuario está editando.
  • Catálogo y preciosConsulta paginada de productos, comparación manual y validación de cambios de precio.
  • Reportes comercialesVistas para Mercado Libre y DYZ que validan los datos recibidos antes de mostrar cifras.
  • Experiencia adaptableInterfaz web y móvil basada en React Native y Expo; demostración sin cuentas comerciales.

Decisiones detrás del sistema

Separación entre cuentas y sesiones

El servidor verifica acceso a cada cuenta. El cliente descarta respuestas tardías de una sesión anterior.

OAuth y operaciones controladas

La conexión implementa state, PKCE y almacenamiento cifrado de tokens. Las escrituras no se reenvían automáticamente cuando el resultado es incierto.

IA que acompaña al usuario

Un borrador tardío no reemplaza la edición humana. La aplicación no presenta al asistente como un operador autónomo del inventario.

Qué demuestra este proyecto

Combina interfaz multiplataforma, APIs comerciales, autenticación y asistencia de IA alrededor de una tarea concreta: atender y gestionar cuentas sin perder el contexto.

Estado y alcance de la muestra

Beta validada localmente con servicios simulados. La conexión comercial, OAuth con cuentas reales y el comportamiento en un teléfono requieren validación adicional. Una exportación Android no equivale a una app publicada en una tienda.

Presentación del proyecto: se comparten sus funciones y decisiones. El código fuente, las credenciales y los registros operativos no forman parte de este portafolio.

Sobre la evidencia revisada

Se revisaron dependencias, contratos de reportes y rutas del backend. La documentación del proyecto registra pruebas de cliente, PHP y recorridos de navegador con datos ficticios; no se presenta una ejecución de CI en GitHub como realizada.

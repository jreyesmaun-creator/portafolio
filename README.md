## Ejecutar la web localmente

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Abrir http://127.0.0.1:8000. La web no necesita instalar dependencias ni conectarse a APIs. En GitHub Pages se publica desde la raíz de la rama principal.
